## Commit Messages

Write commit headlines as an imperative sentence in English, prefixed with a
mark symbol in square brackets followed by a space, ending without punctuation.
Follow the 72-column line-wrapping rule. Detailed descriptions are optional but
recommended for complicated changes.

Marks:

- `[+]` Add
- `[-]` Remove
- `[U]` Update
- `[O]` Optimize
- `[F]` Fix
- `[S]` Modify style
- `[M]` Move (also Modify by convention, but `[U]` Modify is recommended)
- `[R]` Refactor
- `[T]` Test
- `[D]` Tweak documentation
- `[B]` Backup
- `[PR]` Merge commit of pull request

Examples:

- `[+] Add entry for sauricat`
- `[U] Update photos for sauricat`
- `[F] Fix punctuation`
